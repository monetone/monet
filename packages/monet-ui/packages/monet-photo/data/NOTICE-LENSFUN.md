Monet's generated adaptation selects rectilinear lenses with standard polynomial
calibrations, combines camera aliases, retains source filenames and measurement
values, and adds stable profile identifiers. The adapted database remains under
CC BY-SA 3.0. No Lensfun library implementation is included.

Regenerate from the pinned archive using `python3 scripts/generate-lens-catalog.py`.

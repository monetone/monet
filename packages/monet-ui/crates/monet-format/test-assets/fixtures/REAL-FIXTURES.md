# Real-world third-party PSD fixtures

These are genuine Photoshop-authored PSD files (not synthetic, unlike
`sample.psd`/`sample.psb`, which are generated by `gen/gen-psd.mjs`). They
exist to catch importer regressions against real Photoshop output.

This directory holds the only copy of these fixtures. monet-format's own
`tests/psd_real.rs` (the six `real-*.psd`) and `tests/psd.rs`
(`sample.psd`/`sample.psb`), the merged engine's `format_import` tests
(`sample.psd`/`sample.psb`/`sample.xcf`, via `include_bytes!`) and Vision's
`e2e/psd-real-*`, `e2e/format-import` and `e2e/file-drop` specs all read them
from here, so regenerating a fixture updates every consumer at once. The two
generators also write here: `gen/gen-psd.mjs` emits `sample.psd`/`sample.psb`
and `examples/gen_xcf.rs` emits `sample.xcf`. The ag-psd files are covered by
`ag-psd-MIT.txt`.

| File | Source | License | What it exercises |
|------|--------|---------|-------------------|
| `real-adjustment-layers.psd` | [Agamnentzar/ag-psd](https://github.com/Agamnentzar/ag-psd) — `test/read/adjustment-layers/src.psd` | MIT | A real Photoshop document with one raster layer + all 16 adjustment-layer types (Brightness/Contrast, Levels, Curves, Exposure, Vibrance, Hue/Saturation, Color Balance, Black & White, Photo Filter, Channel Mixer, **Color Lookup**, Invert, Posterize, Threshold, Gradient Map, Selective Color). |
| `real-16bit-rgb.psd` | [Agamnentzar/ag-psd](https://github.com/Agamnentzar/ag-psd) — `test/read/16bits/src.psd` | MIT | A real **16-bit/channel** RGB document. 16-/32-bit files store their layer records in an `Lr16`/`Lr32` additional-info block (the main Layer Info is empty), so this guards the high-bit-depth layer-recovery path: a single layer "Layer 1" with a canvas-overhanging, negatively-offset bound (-36,-34 569×591). Without `Lr16` parsing it would flatten to a single "Background". |
| `real-32bit-rgb.psd` | [Agamnentzar/ag-psd](https://github.com/Agamnentzar/ag-psd) — `test/read/32bits/src.psd` | MIT | A real **32-bit/channel** (float) RGB document, 300×300, two layers. Its channels use ZIP-with-prediction (compression code 3); 32-bit float prediction is the TIFF floating-point predictor (byte-planar + per-row byte delta). Without that codec the file failed to parse at all (`Unsupported`). Guards both the `Lr32` recovery and the 32-bit float channel decode. |
| `real-indexed.psd` | [Agamnentzar/ag-psd](https://github.com/Agamnentzar/ag-psd) — `test/read/indexed/src.psd` | MIT | A real **Indexed-colour** (palette) document, 32×32. The 256-colour palette lives in the Color Mode Data section; the image is a single plane of palette indices. Without applying the palette the image renders as grayscale index values (index 20 → [20,20,20]) instead of its real colours (index 20 → white). Guards the Indexed palette decode. |
| `real-bitmap.psd` / `real-bitmap-rle.psd` | [Agamnentzar/ag-psd](https://github.com/Agamnentzar/ag-psd) — `test/read/bitmap/src.psd` and `test/read/bitmap-rle/src.psd` | MIT | Real **1-bit Bitmap-mode** documents, 300×200 — one raw (compression 0), one PackBits/RLE (compression 1). Bitmap data is packed 8 pixels/byte (rows are ⌈w/8⌉ bytes); monet-format treated depth-1 as 1 byte/pixel, underran the merged composite, and imported ZERO layers (the image was lost). Guards the 1-bit unpack (MSB-first, set bit = black) on both compression paths. |

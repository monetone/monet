# Monet organization icon

[`monet-icon.png`](monet-icon.png) is the organization avatar for `monetone` and
the icon used at the top of the repository README. Keep the centered mark inside
the safe area when using a circular avatar crop.

The final export is an opaque 512 × 512 PNG, sized for avatar use. Its background
uses a warm coral-to-amber gradient.

Created with the built-in ImageGen tool on 2026-10-07. The existing Monet app
icons informed the white symbol and gradient treatment.
